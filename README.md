## Project

### MINDI

**음성·텍스트 분석과 회상 대화를 결합한 인지 케어 플랫폼**

어르신의 음성 응답을 분석하고, 일상·회상 대화와 결과 리포트를 제공하는 캡스톤 프로젝트입니다.

`2025년 1학기` · `3인 팀 프로젝트` · `AI 개발 담당`

[프로젝트 자세히 보기](https://github.com/minseoyang/mindi-ai)
