AI 모델을 개발하고, 여러 모델을 하나의 서비스 흐름으로 연결합니다.
진행했던 프로젝트와 직접 맡은 작업을 기록합니다.

## Featured Project

### MINDI

**음성·텍스트 분석과 회상 대화를 결합한 인지 케어 플랫폼**

어르신의 음성 응답을 분석하고, 일상·회상 대화와 결과 리포트를 제공하는 캡스톤 프로젝트입니다.

`2025년 1학기` · `3인 팀 프로젝트` · `AI 개발 담당`

**직접 개발한 부분**

- Whisper를 활용한 음성 전사와 텍스트 전처리
- BERT/KoBERT 기반 텍스트 분석 및 GPT를 활용한 응답·문맥 평가
- 일상·회상 대화 프롬프트와 대화 기록·키워드 추출 모듈
- 모델 결과 결합과 대화 평가 리포트 생성

**협업한 부분**

- 음향 모델의 설계 방향을 제시하고 개선 피드백 제공
- 음향·텍스트 모델을 연결하는 전체 AI 파이프라인 통합 주도

[프로젝트 자세히 보기](https://github.com/minseoyang/mindi-ai)
